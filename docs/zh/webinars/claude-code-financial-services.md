# Claude Code 在金融服务中的应用：从数据分析到遗留系统现代化
与 Anthropic 的技术负责人及我们的内部财务团队一起，深入探讨 Claude Code 如何改变金融服务开发工作流。

观看真实场景应用的现场演示，包括如何分析海量交易数据集、创建预测，以及将遗留 COBOL 系统迁移到云端。

学习来自大型银行的成熟最佳实践，获取可操作的指导，实现更快的迁移并减少人工代码审查的开销。
