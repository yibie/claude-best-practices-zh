# Claude for Nonprofits：让 Claude 在第一天就发挥作用的员工指南
大多数非营利组织员工使用 Claude 的方式都一样：打开对话，粘贴一些内容，得到一个还算不错但很笼统的回答，然后回去继续手工干活。这不是你的问题。真正重要的工作存在于你的文件、你的捐赠者记录和同事的头脑中，而 Claude 目前还看不到这些。

这场 45 分钟的课程面向员工，设计目标是当天就能派上用场。请带上你手头正在赶的那份材料（对大多数人来说，现在就是年终募捐）。在一个虚构非营利组织的数据上，由你与我们一起完成第一步，Claude 会了解你的资料存放在哪里、你的组织如何写作。你会看到，当你的工作所依托的工具被连接起来之后会发生什么变化，而账户中已有的 Claude for Nonprofits 技能会把那份材料从计划推进到一份带有你个人风格的草稿。课程结束时，你会带走：一份本周就能发出的材料、一件下周可以再做一次的事、你的 AI 使用政策允许你输入哪些内容，以及一份给账户管理者的简短说明。Team 和 Enterprise 版本均有覆盖并加以标注。
