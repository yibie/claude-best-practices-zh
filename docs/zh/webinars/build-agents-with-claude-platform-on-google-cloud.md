# 在 Google Cloud 上使用 Claude 模型构建智能体
完整的 Claude Platform 现已登陆 Google Cloud。借助 Google Cloud 上的 Claude 模型（Anthropic 托管），你可以构建能够处理文件、运行代码、使用 Skills（技能）并处理长时程任务的智能体，而这一切都可以在你现有的 Google Cloud 账户中完成。平台由 Anthropic 运营。你的团队使用现有的 Google Cloud IAM 凭证，用量会从你的 Google Cloud 承诺额度中扣减，并统一计入一张 Google Cloud 账单。

欢迎与 Anthropic 和 Google Cloud 一起，看看你能构建什么。你将观看一个智能体如何一步步搭建完成，了解在你的 Google Cloud 项目中如何完成设置与治理，并可在聊天中实时获得问题解答。
