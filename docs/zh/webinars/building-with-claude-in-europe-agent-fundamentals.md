# 在欧洲使用 Claude 构建：智能体基础
Claude Resources

点播

与 Anthropic 和 Mesh-AI 一起，深入探讨如何使用 Claude 构建生产就绪的 AI 智能体。了解智能体式 AI 的基础知识，探索面向欧洲客户的真实部署案例，并了解如何安全地大规模评估和部署智能体。

-   工作流与智能体的区别、"能动性"的哲学基础，以及真正智能体式系统与传统自动化的不同之处。

-   通过动手演示了解智能体开发的技术基础。

-   评估智能体能力并确保你的智能体达到性能基准的实用方法。

-   如何在生产环境中利用 Claude Agents。

-   来自欧洲各地客户部署的洞察，涵盖部署模式、监管考量以及可衡量的成果。
