# 最大化 Claude Code 的价值
Claude Resources

点播

同一个已完成的任务，根据你使用 Claude Code 的方式不同，成本可能相差悬殊。

在本次课程中，我们将梳理一个会话的 token 究竟花在了哪里——是什么决定了 token 的价格，是什么决定了你发送多少 token，以及区分高效会话与浪费会话的少数几个习惯和设置。

## 特邀演讲嘉宾

-   

    Lydia Hallie

    Anthropic 技术团队成员


## 你将学到

-   如何选择合适的模型和努力程度。学习针对每个调节项的简单经验法则：了解得不够 → 用更大的模型；努力得不够 → 提高努力程度。

-   如何降低长会话的成本。学习何时使用 /clear、/compact 和 /rewind，从而永远不会为重新发送已完成的任务付费。

-   如何充分利用提示词缓存。识别哪些变更会破坏缓存（模型、努力程度、快速模式）以及进行这些变更的正确时机，让你的历史记录始终保持仅为输入价格十分之一的成本。

-   如何保持上下文精简。让嘈杂的命令静默，把高输出量的工作交给子智能体，这样只有答案会返回。

-   如何停止为你用不到的启动上下文付费。学习只需十分钟的清理，就能让之后的每个会话都受益——运行 /context 查看 CLAUDE.md 和 MCP 服务器在每一轮中增加了什么，并删掉不属于那里的内容。
