# 统一版 Claude：对管理员意味着什么

Chat 与 Cowork 正在合并为跨 web、桌面端和移动端的单一、更简洁的 Claude 体验：从提出一个简单问题到产出包含完整分析的交付物，一切都在同一个地方完成。

我们邀请管理员和安全团队加入 Anthropic 团队，一同了解贵组织将迎来哪些变化，以及变化的时间安排。参会后您将明白：为什么统一的 Claude 对您的团队更简单、对您而言更易于治理，以及具体该如何完成切换。最后我们会留出问答时间。
