# 构建 Claude 商业智能体

AI 正在迅速改变商业格局，消费品牌与平台正积极行动以应对变化。在今天的网络研讨会中，Ali Shazal 将带你了解我们面向消费者智能体和商家智能体的全新蓝图。他将深入讲解零售、旅游、电信和娱乐领域的参考实现，并分享他在与基于前沿 AI 构建此类体验的团队合作中积累的未经修饰的建议。欢迎带来你在构建、认证、延迟等方面最棘手的问题。我们将在会议期间进行现场问答。
