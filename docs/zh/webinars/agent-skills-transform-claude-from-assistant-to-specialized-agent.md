# Agent Skills：将 Claude 从助手转变为专用智能体
了解如何将 Claude 从对话式助手转变为专用智能体，执行针对你特定需求量身定制的复杂、可重复工作流。加入 Anthropic 应用 AI 团队的 Marius Buleandra，他将分享 Agent Skills 如何自动化那些过去需要数小时的任务——从客户准备工作到企业文档创建——并向你展示如何构建你自己的自定义技能。

在这场技术深入探讨中，你将了解 Skills 背后的架构，观看预构建技能和自定义技能的现场演示，并学习创建技能的最佳实践，让技能承载你组织独特的工作流与专业知识。
