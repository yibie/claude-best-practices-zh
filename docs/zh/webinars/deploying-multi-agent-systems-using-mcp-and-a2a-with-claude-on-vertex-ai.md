# 在 Vertex AI 上使用 Claude，通过 MCP 与 A2A 部署多智能体系统

探索如何构建并连接协同工作的 AI 智能体，打造高性能的多智能体系统。本次由 Anthropic 与 Google Cloud 联合主讲的网络研讨会，将深入探讨如何在 Vertex AI 上使用 Claude，借助 Model Context Protocol（MCP）与 Agent-to-Agent 协议（A2A）实际落地多智能体系统。通过现场演示与真实案例，我们将展示这些标准如何实现智能体之间的工具集成、上下文共享、任务委派等能力。
