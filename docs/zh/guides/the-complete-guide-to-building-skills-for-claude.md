# 构建 Claude Skills 完整指南

Skill 是一组指令——打包成一个简单的文件夹——用于教会 Claude 如何处理特定任务或工作流。你无需在每次对话中重新解释自己的偏好、流程和领域专业知识，Skills 让你只需教 Claude 一次，之后每次都能受益。

本指南涵盖构建高效 Skills 所需了解的一切——从规划、结构到测试与分发。无论你是为自己、为团队还是为社区构建 Skill，都能在文中找到实用的模式和真实案例。
