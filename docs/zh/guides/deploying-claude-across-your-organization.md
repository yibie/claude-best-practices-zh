# 在整个组织内部署 Claude：Anthropic 如何使用 Cowork
一份关于在整个企业范围内部署 Claude Cowork 的实用指南，包含用例、时间线，以及来自 Anthropic 和其他组织的经验教训。

本指南将逐步介绍如何在一个业务职能中部署 Claude Cowork：从哪里开始、如何组织试点，以及将行之有效的做法规模化推广的最佳实践。其中的示例来自 Anthropic 自身的财务、法务、销售和产品团队，以及在生产环境中运行 Claude Cowork 的客户，包括 Thomson Reuters、Zapier 和 Jamf。
