# 在整个组织内推广智能体式编程
过去一年里，Claude Code 这类智能体式编程工具已成为工程师的必备工具，为各种规模的组织充当力量倍增器。在这一新格局下，技术负责人面临一个关键问题：如何将智能体式编程工具从少数早期采用者推广到整个工程组织？

本指南基于 Anthropic 应用 AI 团队的洞见以及我们从客户身上总结的经验，分享在整个组织内推广智能体式编程工具的最佳实践。
