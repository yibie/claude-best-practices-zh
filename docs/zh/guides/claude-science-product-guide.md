# Claude Science 产品指南
Claude Science（测试版）是 Anthropic 针对每项实验所背负的繁重负担给出的答案：这是一款覆盖生命科学每一个数字化步骤的应用，设计上紧邻科学家的数据运行，并产出可追溯、可复现、可辩护的结果。

本指南首先说明何时该选用哪个 Claude 界面，随后深入探讨如何在研究机构内部署 Claude Science，包含客户案例、推广路线图，以及对 CIO 和 IT 负责人所提问题的解答。
