# 代码现代化实战手册

IT 与工程组织正处在十字路口。是继续维护遗留系统，还是升级它们。是维持系统运转，还是把宝贵的工程资源投入到将代码库迁移到 Python 或 Java 上。是坚守久经考验的单体架构，还是踏上将其拆解为微服务的复杂旅程。

好消息是？你不必在代码现代化与交付下一个重要功能之间二选一。本实战手册（playbook）提供了可执行的策略，帮助你识别与战略性业务目标相一致的高投资回报（ROI）现代化机会。
