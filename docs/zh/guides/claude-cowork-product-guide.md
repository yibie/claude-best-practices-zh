# Claude Cowork 产品指南

大多数 AI 工具都是对话式的。你在聊天窗口里提出一个问题，得到一个回答，而把那个回答变成实际成果——一份演示文稿、一份文档、一张电子表格、一封已发送的邮件——这项工作仍然由你完成。

Claude Cowork 是为工作本身而构建的，而不只是为答案。它是 Claude 的一个版本，可以读写你计算机上的文件、使用你已连接的工作应用，并代表你运行多步骤任务。本指南面向分析师、PM、运营人员、研究人员、市场人员、招聘人员，以及任何日常工作中需要把信息在不同系统之间流转的人。
