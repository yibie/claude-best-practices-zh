# Claude Cowork 产品指南
Claude Resources

我们分享如何开始使用 Claude Cowork，包括那些能把你的想法变成精美交付物的工作流、习惯和插件。

大多数 AI 工具都是对话式的。你提出一个问题，得到一个答案，而把这个答案变成有用的东西——一份演示文稿、一份文档、一张电子表格、一封邮件——这项工作仍然是手工完成的。

[Claude Cowork](https://claude.com/product/cowork) 是我们全新的知识工作智能体，让你可以把这项工作委托给 Claude，从而专注于解决那些占用你时间的更具战略性和创造性的问题。Claude Cowork 运行在 Claude 桌面应用中，可以读写本地文件，跨 Slack 和 Google Drive 等已连接的应用工作，并将多步骤任务推进到真正的交付物，同时附上指向实际文件和消息的引用。你描述目标、期望的结果和节奏，Claude 就会列出步骤并完成工作，确保你全程参与其中。

为了帮助你入门，我们整理了一份 Claude Cowork 实用产品指南。我们分享了：

-   **Claude Cowork 与对话式 AI 工具的不同之处**及其核心能力，包括本地文件访问、子智能体、长时间运行的工作和定时任务
-   **一个产品矩阵，帮助你理解何时使用哪种工具：** 用于对话式起草的 chat、用于编码的 Claude Code，以及用于跨应用知识工作的 Claude Cowork
-   **设置和系统要求**、权限模型，以及首先可以尝试什么
-   **七种常见的 Claude Cowork 工作流**，包括研究简报、会议准备和周期性报告
-   **如何使用插件**来完成营销和产品管理等特定的知识工作
