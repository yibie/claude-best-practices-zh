# 智能体式编程入门
AI 辅助编程在过去几年里发展迅速。曾经只能建议下一行代码的工具，如今已能通过分析你代码中的模式来预测整个函数。

最新的演进更进一步：这些系统不再预测你接下来要输入什么，而是通过读取你代码库中的文件、运行测试并不断迭代，自主执行多步骤的开发任务，直到目标完成。

## 什么是智能体式编程？

智能体式编程将 AI 从自动补全转变为自主任务执行器。传统的编程助手等待你逐行输入，并建议接下来写什么。智能体系统则接收一个高层目标，将其拆解为离散的步骤，独立执行这些步骤，并根据来自你环境的反馈调整其方法。

关键区别在于自主性和范围。传统 AI 工具分析你编辑器中可见的代码，并建议下一个片段。智能体式编程工具会读取整个代码库，理解跨目录的文件关系，执行命令以验证更改是否生效，并不断迭代，直到测试通过、需求满足。这种自主性贯穿整个开发周期，每一步都无需你手动编排工作流。

## AI 编程工具是如何演进的

### 代码预测与补全

IDE 自动补全扩展这类工具会分析你编辑器中可见的代码，以预测你接下来可能输入的内容。这些系统擅长处理重复性模式，例如生成 REST 端点样板代码、按照既有约定创建测试结构，以及实现常见算法。

预测模型会考虑你的即时上下文。当你编写函数签名时，工具会根据函数名、参数类型和周边代码建议实现。当你开始输入 import 语句时，它会根据已导入的内容和常见用法模式推荐包。

局限在于范围。自动补全工具可用的上下文窗口有限，通常只分析你当前的文件或少量邻近文件。它们无法追踪数据流穿过你的应用架构，也无法理解某个服务中的更改如何影响依赖它的服务。

### 对话式 AI 聊天界面

像 Claude.ai 这样的基于浏览器的编程助手为 AI 编程工具增加了对话能力。这些工具不再在你输入时建议代码，而是通过分析粘贴的代码片段、缺陷描述和优化问题，围绕你的代码问题展开对话。

这些界面擅长分析与指导。粘贴一条缓慢的数据库查询，即可获得优化建议。描述一个架构决策，即可获得权衡分析。粘贴一条错误信息，即可探索排查思路。

对话形式支持迭代细化。你提出一个笼统的问题，收到初步回复，基于该回复澄清你的需求，并逐步缩小到具体解决方案。当问题尚未完全定义，或你需要在确定实现方案之前探索不同方法时，这种来回交流非常有效。

但对于涉及多个文件的任务，这种方式就变得不切实际。重构一个被另外三十个文件导入的模块，意味着要把每个文件粘贴到聊天中、手动跟踪哪些文件需要更新、把建议的更改复制回每个文件，并确保所有修改保持一致。聊天界面提供指导，但编排实现仍需手动完成。这正是智能体式编程系统旨在填补的空白。

## 智能体式编程如何运作

### 上下文收集与规划

智能体式编程系统在项目层面而非文件层面运作。当你提供一个目标时，系统会分析完成该目标所需的相关上下文：读取配置文件以了解你的项目设置，检查测试文件以查看现有的测试覆盖率模式，追踪导入关系以映射模块之间的依赖。

随后系统会制定完成该目标的计划。这不是一份静态清单，而是一种随着系统收集更多信息而不断演进的自适应方法。如果你的目标是"为 API 添加身份验证"，计划可能从分析现有的路由定义开始，确定哪些端点需要保护，检查是否已存在身份验证中间件，并确定用户会话管理应在何处实现。

### 实现与协调

实现阶段涉及跨代码库读取和写入文件。与仅在单个文件内建议更改的自动补全工具不同，智能体系统会修改多个相关文件以保持一致。添加身份验证可能需要更新路由处理器、创建中间件函数、修改数据库模式、调整 API 客户端代码、更新文档，并为所有这些更改添加测试覆盖率。

这种自主工作流将开发从"写代码、运行测试、读取错误、修复代码、重复"转变为"定义目标、审查建议的更改、批准实现"。你通过审查计划和批准文件更改来保持控制，而系统则处理迭代调试循环、对现有代码模式的研究，以及跨多个文件的更改协调。

## 使用 Claude Code 进行智能体式编程

[**Claude Code**](https://claude.com/product/claude-code) 将智能体能力带入你的终端环境。与需要不断复制代码的基于浏览器的工具，或只能分析可见文件的 IDE 扩展不同，Claude Code 直接在你的项目目录中运行，可完整访问你的代码库。



### 安装与启动

在终端中安装 Claude Code：

```
npm install -g @anthropic-ai/claude-code
```

然后在你的项目目录中启动它，开始编程：

```
claude
```

### Claude Code 如何工作

Claude Code 会根据请求读取你的整个项目上下文。当你询问架构或请求更改时，它会分析文件结构，理解 package.json 或 requirements.txt 中声明的依赖，追踪模块之间如何交互，并识别你代码库中既有的模式。

多文件操作变得简单直接。请求"将这个基于回调的代码重构为使用 async/await"，Claude Code 会找出所有使用回调模式的文件，为每个文件更新为 async/await 语法，修改错误处理以使用 try/catch 块，更新相关测试以处理异步模式，并验证你的整个测试套件仍然通过。

### 文件系统访问与权限

文件系统访问使基于 Web 的工具无法处理的工作流成为可能。Claude Code 会按照适当的命名约定创建新文件，将代码组织到逻辑清晰的目录结构中，在添加依赖时更新配置文件，并与你现有的项目组织模式保持一致。

权限模型确保你保持控制。默认情况下，Claude Code 在修改文件之前会请求批准，并准确显示它计划做出哪些更改。你审查建议的修改，批准你同意的更改，并对不符合要求的更改请求修订。

### 与开发工作流集成

与你的开发工作流集成意味着 Claude Code 会与你已经在使用的工具交互。它会运行 npm 命令来安装依赖，执行 Jest 或 pytest 等测试运行器，使用 Git 进行提交和分支操作，并启动开发服务器以验证更改在运行中的应用里是否生效。

你可以通过连接 Model Context Protocol（MCP）服务器进一步扩展这些能力，这些服务器为 Claude Code 提供来自开发环境中其他工具和系统的全面上下文。

## 真实应用

### Rakuten 的七小时自主实现

[Rakuten](https://www.claude.com/customers/rakuten) 的工程团队用一项任务挑战了 Claude Code 的智能体能力：在 vLLM 中实现一种特定的激活向量提取方法。vLLM 是一个开源库，包含横跨 Python、C++ 和 CUDA 的 1250 万行代码。Claude Code 在七小时的持续自主工作中完成了整个实现。

> "'在那七个小时里我没有写任何代码，我只是偶尔提供指导。'"

\- Kenta Naruse，Rakuten 机器学习工程师

最终实现与参考方法相比达到了 99.9% 的数值精度，展示了该系统理解复杂的多语言代码库、为复杂算法规划实现方法，并交付生产级结果的能力。

**Rakuten 的转型指标：**

-   **功能交付提速 79%**（24 天 → 5 天）
-   **7 小时**的自主实现，人工干预极少
-   复杂算法重构达到 **99.9%** 的准确率
-   工程团队的并行任务执行能力提升 **5 倍**

正如 Rakuten 商业 AI 总经理 Yusuke Kaji 所解释的："你可以让五个任务并行运行，把其中四个委托给 Claude Code，同时专注于剩下的那一个。"

## Claude Code 入门

使用 npm 安装 [Claude Code](https://claude.com/product/claude-code) 后，导航到一个项目目录并启动会话：

```
claude
```

尝试几个不同的任务，看看 Claude Code 如何理解你的代码库。

### 理解项目架构

```
Explain the structure of this codebase and how the main components interact
```

Claude Code 会读取你的文件并提供架构概览，帮助你或新团队成员理解项目组织。

### 分析代码质量

```
Review the authentication module for potential security issues
```

Claude Code 会检查相关代码，识别诸如凭据泄露或验证不足等问题，并建议具体的改进措施。

### 调试并修复错误

```
Find all N+1 query problems in our GraphQL resolvers and implement DataLoader batching
```

Claude Code 会分析你的整个代码库，找出导致 N+1 问题的具体 ORM 模式，并实施修复。



## 先慢后快，逐步扩展

在与 Claude Code 协作的过程中，你会逐渐形成直觉，判断哪些任务最适合自主执行，哪些任务更适合用传统开发工具处理。一些能带来快速收益的即时应用包括：

-   为未覆盖的代码路径实现**测试自动化**
-   为遗留系统**生成文档**
-   对技术债务进行**例行重构**
-   为需求明确的功能进行**功能实现**

每次交互都是一次机会，让你了解 Claude Code 如何在你的特定代码库中处理问题。开始使用 [Claude Code](https://claude.com/product/claude-code)，或访问我们的[文档](https://docs.claude.com/en/docs/claude-code/overview)了解更多。
