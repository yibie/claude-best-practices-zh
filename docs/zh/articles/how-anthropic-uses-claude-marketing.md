# Anthropic 的增长营销团队如何借助 Claude Code 将广告制作时间从 30 分钟缩短到 30 秒

在使用 Claude Code 之前，Austin Lau 这辈子从未写过一行代码。这款产品刚发布时，他甚至还得用 Google 搜索如何在自己的电脑上打开终端。

"我们发布 Claude Code 时，我的第一反应是，我完全不知道这个产品是干什么用的，"Anthropic 的增长营销人员 Austin 说道。"作为一名营销人员，我当时确实没太搞明白——这个用例对我来说还不够直观。"

但好奇心最终占了上风。

Anthropic 的一位同事曾在公司的 Slack 工作区里发过一篇指南，讲的是非技术岗位的员工如何安装 Claude Code。Austin 决定照着这份指南试一试。

一周之后，Austin 已经构建出两个从根本上改变了他工作方式的工作流：一个只需点击一次就能生成广告创意变体的 Figma 插件，以及一个 Google Ads 文案工作流，它能帮他头脑风暴并打磨广告文案，然后导出为可直接上传的 CSV 文件。过去每条广告要花 30 分钟，现在只需 30 秒。

下面就是他做到这一切的经过，以及营销人员可以从他使用 Claude Code 的经历中学到什么。

‍

## **问题：淹没在文案和创意变体之中**

大规模投放效果营销，需要持续产出源源不断的新鲜创意。仅 Google 的自适应搜索广告就要求 15 条互不相同的标题。每隔几周，这些文案就需要更新一次——同时还要保持品牌调性并传达价值主张。

"这件事的难点在于，当你在这个层级上运作时，你需要非常、非常频繁地更新文案，"Austin 解释道。"而且由于 Google 对字符数有严格限制，它的文案要求也没那么灵活。"

过去的流程是这样的：打开 Google Sheets，头脑风暴标题和描述，手动核对字符数，复制粘贴到 Google Ads，然后重复。

对于视觉广告，流程还要更繁琐。Austin 会打开 Figma，把现有的画框复制多次，切换到 Google Doc 取出他的标题文案，再切回 Figma 把文案粘贴进去，如此反复——而且要在十个甚至更多变体和多种宽高比上全部做一遍。

"这些时间累加起来非常、非常快，"Austin 说。

## **解决方案：两个消除了营销琐事的工作流**

借助 Claude，Austin 最终构建出两个改变了他日常工作的流程。但 Austin 的第一个项目，其实是做一个简单的计算器应用。

"我实际上让 Claude 做的第一件事，是给我做一个非常简单的计算器应用，只是想看看它会怎么回应，"他回忆道。"Claude 基本上帮我创建了后端，还有一个很简陋的前端。然后它基本上告诉我，'这是你实际运行它的方法。'"

那次小小的实验改变了他对自己能在工作任务中实现什么的看法。

### **用于生成创意变体的 Figma 插件**

制作广告变体意味着无休止的复制、粘贴，以及在 Figma 和 Google Docs 之间来回切换。

于是 Austin 用 Claude Code 构建了一个 Figma 插件。这个项目花了大约 45 分钟到一小时来构建，但现在每次他要跨多种宽高比更新一大批创意时，都能为他节省将近 30 分钟。

一开始，他打开 Claude Code，通过一段提示词描述了自己的问题："Claude，我在用 Figma。我真的很想解决这种重复复制粘贴的难题。你能帮我构建一个 Figma 插件来帮我解决这个问题吗？"

Claude 随后去做了调研，评估了构建插件的最佳方式、有哪些限制，然后开始做原型。经过一番排查之后，Austin 在 Figma 里装上了一个可用的插件。



Austin 的插件让他可以从 Google Sheet 粘贴标题文案，然后一键生成几十个广告变体。

"我要做的只是指定创意的画框，然后一次性复制粘贴所有我想更新的不同变体和文案，再点一下按钮，这个 Figma 插件就会为那张图片创建出所有不同的排列组合，"Austin 解释道。

### **Google Ads 文案生成**

对于自适应搜索广告，Austin 构建了一个工作流，借助现有的广告系列和广告效果数据来帮助头脑风暴并生成可直接上传的广告文案，从而帮助判断哪些类型的信息更能引起潜在客户的共鸣。这个工作流每周在文案创作和字符数校验上为他节省数小时。把机械性任务上省下的时间利用起来，Austin 现在可以运行更多文案实验，并更快地针对真正效果最好的方案进行迭代。

开始使用时，他在 Claude 里输入 `/rsa`——这是他专为自适应搜索广告创建的自定义斜杠命令。Claude Code 会询问广告系列数据、现有文案和关键词，然后将他提供的输入与他为 Anthropic 品牌调性与语气、产品准确性以及 Google Ads RSA 最佳实践创建的 [Agent Skills](https://claude.com/resources/articles/skills) 进行交叉比对。

但输出只是一个起点。

"Claude 是个很棒的头脑风暴伙伴，但有时它第一次并不能做对，"Austin 解释道。"我做的很多工作都是反复推敲、来回打磨，帮助文案随着时间不断精进。"

这种打磨很重要，因为 Austin 会根据他所了解的、能引起 Anthropic 受众共鸣的内容来评估每一条标题。价值主张是否站得住脚？语气是否恰当？是否能在竞争对手中脱颖而出？一旦文案感觉对了，Claude Code 就会把所有内容整合成一个可供上传的 CSV 文件。

而这一切都建立在一个由人打下的基础之上。"我们提供给 Claude 的所有文案和示例，都是与产品营销和文案团队合作撰写的，"Austin 说。这个扎实的起点意味着，在 Claude 开始头脑风暴之前，人的判断就已经融入其中。



该工作流会把相关的广告系列和广告组列，以及每条广告的 15 条标题和 4 条描述，导出到一个 CSV 文件中，可直接上传到 Google Ads（需经过人工审核）。

## **构建你自己工作流的最佳实践**

Austin 的经历为营销人员——或者说任何没有技术背景的人——提供了实用的指导，帮助他们用 Claude Code 构建自定义工具。

**从小的、重复性的步骤开始**

"我的建议是：如果你想尝试 Claude Code 这样的工具，就先想一想，在你的工作中，你已经识别出哪些是重复性的、或者你认为可以自动化的部分，然后从一个非常、非常简单的小事开始，"Austin 解释道。

例如，Austin 的第一个项目就是构建他的计算器应用，先看看 Claude 是如何工作的。

**让好奇心驱动你的工作**

Austin 形容自己是"那种人——如果我对某件事非常好奇，就会好奇到几乎固执的地步，非得找出答案不可"。正是这种坚持，把一个他不知如何交互的空白终端，变成了他每天都在使用的可用工具。

**像向同事解释问题一样和 Claude 交流**

"你不需要会写代码。你只需要知道如何以非常清晰、简洁的方式解释你的难题以及你想解决什么，"Austin 说。

非技术岗位的员工本来就是各自领域的主题专家。他们了解自己的工作流，能感受到摩擦点，也清楚自己需要什么样的输出。Claude Code 赋予了他们自行解决任何反复出现的技术问题的能力。

**在已有资源的基础上构建**

对于那个 Figma 插件，Austin 让 Claude Code 参考了现有的 Figma API 文档。利用这些现有文档，Claude 自行做了调研，并为 Austin 构建了一个可供试验的原型。一个勉强能用的原型，就足以证明 Austin 心中所想的那个概念，最终催生出一个可用的产品。

**更大的图景**

在职业生涯的大部分时间里，Austin 都认为某些事情是可望而不可即的。如果他需要安装一个跟踪像素，就得请工程师来装。如果他需要构建一个自定义工作流，就得向支持团队提交工单。

"我想说，几年前，如果你有构建类似这个工作流的想法，你大概需要一支工程师团队来支持你，"Austin 说。"现在，有了 Claude Code 这样的工具，作为一名非技术营销人员，我实际上可以自己去构建这些东西。所以，'我希望这东西存在'和'我实际上能自己把它做出来'之间的差距，其实比人们意识到的要小得多。"

他现在已经向同事和客户演示了自己的工作流，他们的反应都一样：为什么*我们*没做这个？

## **营销人员的下一步**

Austin 认为增长营销人员的角色正在迅速演变。"我认为增长营销正朝着几乎像产品经理的方向发展，"Austin 说。"我们不仅能执行广告系列，还能真正构建产品来帮助我们达成目标。"

Austin 并不是 Anthropic 唯一用 Claude 构建东西的营销人员。在整个营销组织中，各团队都在取得类似的成果：

-   **网红营销（Influencer Marketing）** 使用 Claude 为网红和播客撰写脚本，每月腾出 100 多个小时专注于更高价值的工作
-   **客户营销（Customer Marketing）** 用 30 分钟而不是 2.5 小时起草案例研究，每周节省 10 小时
-   **数字营销（Digital Marketing）** 构建了 Web 开发工作流，使团队生产力同比提升 5 倍
-   **产品营销（Product Marketing）** 使用 Skills 和 Projects 创建发布简报，每次发布节省 5-10 小时
-   **合作伙伴营销（Partner Marketing）** 为销售团队构建了自助式活动赋能工具，将展会筹备时间减少了 40%

"大多数营销人员对待 AI 的方式可能都差不多，他们只是把它看作帮助简化撰写文案或头脑风暴之类工作的一种方式，"Austin 说。"但他们还没有真正想清楚，哪些实际领域是他们可以真正把 Claude 这样的工具嵌入到工作流中的。"

对于采用 Claude Code 这类工具的团队来说，一个机会正在形成：把更少的时间花在重复性的执行上，把更多的时间花在对他们的工作真正重要的事情上。
