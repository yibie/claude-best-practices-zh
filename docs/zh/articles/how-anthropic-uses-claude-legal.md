# Anthropic 法务团队如何借助 Claude 将审查时间从数天缩短至数小时

在 Anthropic，Mark Pike 的办公桌上摆着一部年代错乱得有些滑稽的老式投币电话。拿一枚"法律挑战币"轻敲它——没错，真的可以——它就会响起来。一个 AI 机器人接听电话，弄清你的需求，然后把你转接给合适的律师。

这是 Mark 自己搭建的。而他并不会写代码。

"我不会说我在做的事是在学编程，"Anthropic 的产品律师 Mark 说。"我与 Claude 合作完成某些涉及编程的项目，但写代码的人不是我。我只是非常擅长排查问题。"

## **问题：淹没在事务性工作中**

在引入 Claude 之前，Mark 的一天和任何一位企业内部律师没什么两样。回复合规文件和客户问卷。起草和更新服务条款与隐私政策。在发布前的几个小时里审查博客文章和邮件文案。

"在 Claude 之前，我有一大堆事务性的琐碎工作，"Mark 说。"那些我会拖到一天结束才做的事，因为我知道它们很耗时，但又用不上我大脑里最好的部分。"

流程总是千篇一律：在 Slack 上收到一条消息或一封邮件，打开 Google 文档，阅读，插入评论，回去告诉客户他们需要做什么，然后再来回沟通两三次，才能把事情推进到理想状态。

Anthropic 的法务团队决定对此做点什么。他们走进一间会议室，在白板上列出自己的痛点：什么在消耗我们的精力？什么让人感觉重复？什么阻碍了我们去做有影响力的工作？

清单很长。拖了好几天的营销审查周转。耗费数小时人工比对的合同修订。模式相似却需要从头重建格式的隐私影响评估。甚至连纸质邮件的分拣都算在内。

"目标是让法务团队从'说不部门'转变为跨职能的思想伙伴，"Mark 解释道。"当法务团队对 AI 充满热情时，我们就不再是更广泛推广的阻碍者。其他团队看到我们在做什么，就会意识到他们也能做到。"

## **解决方案：四个落地的工作流**

在几个月的时间里，经过大量实验，法务团队一些最大的痛点已经演变为可重复的工作流。

### **营销审查工作流**



法务团队的营销材料自查工具让市场推广部门的员工在提交给法务做最终审核之前，先自行审查自己的内容。

这个问题对任何支持营销的法务团队来说都不陌生：临近发布、周转时间紧张的博客文章审查。

Mark 和团队构建的解决方案是一个固定在 Slack 里的自助审查工具。营销人员粘贴内容，Claude 使用一个"Skill"（一个包含法务团队历史指导和审查框架的文件）对其进行分析。该工具会识别诸如宣传权问题、夸大表述和统计准确性问题等，并将其标记为低、中或高风险。它会在营销人员提交工单之前就给出修改建议。

"它会标出诸如'嘿，你有这个标志的使用权吗？这个统计数据准确吗？这个商标需要加上符号'之类的问题，"Mark 解释道。"做完这些之后，再在法律队列里提交工单。"

当内容确实提交正式审查时，它会被分诊给合适的律师，并附带预先标记的问题。自从在队列中启用这个工具以来，周转时间从两到三天降到了 24 小时。

"我仍然会读那篇博客文章。我仍然在审查这份工作，"Mark 指出。"但这帮助我们用更快的速度推进。"

### **合同修订工具**

比较合同版本并建议备选措辞是一项耗时的工作。

Claude 现在可以在 Google Docs 和 Office 365 等工具中比较文档版本，突出显示变更，并从商业实战手册中推荐措辞。团队成员摸索出了如何让 Claude 在 Google Docs 内工作，实时以建议修改的形式添加评论。审查合同的人可以直接在文档中提问："嘿 Claude，你觉得这段措辞能满足我们的需求吗？"并立即得到反馈。

"合同修订是大家对 AI 最期待的用例，"Mark 说。"而 Claude 真的很擅长——它为我们节省了数小时的人工比对。"

Mark 和他的同事还编写 [Skills](https://claude.com/resources/articles/skills)——即存储在文件中、由 Claude 根据任务读取的专业指令和最佳实践——以进一步简化特定类型文档的审查，从保密协议到第三方供应商协议。

### **外部业务活动审查**



法务团队的外部业务活动申请表加快了为 Anthropic 员工评估利益冲突审查的流程。

在 Anthropic，如果员工想提供咨询或加入非营利组织董事会，需要填写一份表格以排除利益冲突。雇佣律师过去要在例行的利益冲突表格审查上花费大量时间。

他们由 Claude 驱动的工作流让员工填写一份表格，注明所在部门、经理以及拟开展活动的描述。Claude 根据利益冲突政策框架分析提交内容，并通过 Slack 将建议发送给律师审批。

"过去，你得和员工面谈，来回沟通一番才能弄清细节和可能存在的冲突。有了这个工作流，Claude 会读取表格，需要时还会索取更多信息，并给出结果建议，"Mark 解释道。"然后它带着建议进入我们的队列。"

### **隐私影响评估（PIA）**

即使模式相似，从头撰写隐私影响评估也很繁琐。团队现在使用 [MCP（Model Context Protocol）](https://modelcontextprotocol.io/)服务器将 Claude 连接到存放以往 PIA 的 Google Drive 文件夹，并用一个 Skill 指导 Claude 掌握格式和关注点。

例如，律师可以让 Claude 基于一个存放以往 PIA 的文件夹撰写一份新的 PIA。

"Claude 非常擅长读取这些上下文，并运用那个 Skill 创建新模板，帮我继续推进当天的工作，"Mark 说。

## **在法律工作中使用 Claude 的最佳实践**

Mark 的经验为采用 AI 的律师和法律专业人士提供了实用指导。

**从痛点出发，而非从技术出发**

问问自己：我们手头最繁忙的工作是什么？什么在消耗我们的精力？什么让人感觉重复？"不要从'AI 能做什么'开始，"Mark 建议道。"从'我们希望自己不必做什么'开始。"

**用自然语言描述你的需求**

"我第一次看到 Claude Code 时，它看起来像《黑客帝国》里的东西，"Mark 回忆道。"一行行代码滚动而过，乍看之下令人生畏。但随后我只是输入了一句普通的话，描述我想要什么。然后它就成了。"

**内置人工监督**

AI 仍然可能产生幻觉。务必核实引用和输出。把 AI 用于初稿、分诊和起草，而非最终判断。Mark 的工作流会转交律师审批，而不是绕过他们。"我们知道 AI 系统仍可能产生幻觉，我们要确保核实和检查引用，确认 AI 没有凭空捏造。"

**用 Skills 保持一致性和语气**

[Skills](https://www.anthropic.com/news/skills) 是包含指令、脚本和资源的文件，Claude 会在与任务相关时动态加载它们。它们将专业知识打包成可重复使用的工作流，让 Claude 更擅长专业任务。

Mark 以两种方式使用 Skills。第一，用于工作流一致性：他的营销审查 Skill 包含法务团队的指导，帮助 Claude 识别问题，并在营销人员提交给法务之前指导他们如何修改。

第二，用于语气和写作风格：Mark 让 Claude 分析了他最近的十份备忘录，学习他的格式偏好以及他在产品法律简报中通常会包含的内容。现在他可以把产品路线图上传到 Claude 项目，调用他的 Skill，得到一份带有他个人语气风格的初稿。

不同的 Skill 服务于不同的专业领域：雇佣、商业、隐私、公司。一个 Skill 可以教 Claude 像雇佣律师那样写作，或像产品律师那样格式化备忘录。

**借助 MCP 连接你的知识来源。**

MCP 让你可以把其他系统中的信息拉取到 Claude 中。Anthropic 法务团队使用 MCP 将 Claude 连接到 Google Drive、JIRA 工单、Slack 消息和 Google Calendar。拉取所有这些信息意味着在恰当的时间呈现恰当的上下文。

## **更大的图景**

Mark 设想了一个未来：新律师通过提示词库和 Skills 继承团队积累的知识。新员工不必翻阅旧备忘录来学习内部风格，而是可以调用一个 Skill，教 Claude 像团队的产品律师那样写作，或按公司法务组偏好的方式格式化董事会会议纪要。

"我们不是在取代律师，"他说。"我们是在拓展可能性的边界。我们是在用他们所需的技能和工具赋能他们，让他们把最好的工作做出来。"
