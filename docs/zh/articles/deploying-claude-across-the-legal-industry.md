# 在法律行业部署 Claude
我们分享法律专业人士如何使用 Claude 加速其最繁琐的工作流，涵盖何时使用哪款产品、新的连接器、执业领域插件，以及一份三阶段采用路线图。

2026 年 [FTI Consulting / Relativity 总法律顾问报告](https://www.fticonsulting.com/about/newsroom/press-releases/ai-adoption-in-corporate-legal-departments-doubles-according-to-the-general-counsel-report)发现，87% 的总法律顾问现在报告其团队内部已使用生成式 AI，高于上一年的 44%，而 2023 年这一比例仅为 20%。工作要求正变得越来越高：案件更加复杂，客户期望更快的周转时间。领先的律所和法律部门，正是那些将智能体式 AI 融入律师实际执业方式中的机构。

在整个行业中，法律团队正在合同审查与修订、并购尽职调查、隐私影响评估、监管监测、诉讼准备以及外部律师监督中运行 Claude。大多数团队为此同时运行不止一款 Claude 产品：

-   Chat 用于对话与研究；
-   Claude Cowork 用于跨文件与应用的案件级工作；
-   Claude for Microsoft 365 用于在 Word、Excel、PowerPoint 和 Outlook 中度过的时光；
-   Claude Platform 用于构建和部署定制法律应用。

为帮助领导者规划推广（rollout），我们编写了一份面向法律行业的实用部署指南。它涵盖每款 Claude 产品、专为法律工作打造的连接器与执业领域插件，以及团队今天即可执行的三阶段采用计划。

在本指南中，我们分享：

-   一份产品矩阵，说明何时使用 Chat、Claude Cowork、Claude Microsoft 365 加载项和 Claude Platform
-   将 Claude 定制为律所或内部团队实战手册（playbook）、先例和行文风格的连接器、Skills（技能）、子智能体和插件
-   12 个预构建的执业领域插件，涵盖商业、公司、雇佣、隐私、产品、监管、AI 治理、知识产权和诉讼工作
-   按内部部门、交易类执业、诉讼与争议、合规与监管组织的用例
-   Anthropic 自己的法律团队如何使用 Claude 加速其最繁琐的流程，例如合同修订和营销内容审查
-   对 CIO 和 IT 领导者关于托管、留存、特权保护、SSO 和审计等问题的解答
