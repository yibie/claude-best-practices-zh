# 使用 Claude Cowork 在整个企业范围内部署智能体式 AI
就在几年前，在工作中使用 AI 还意味着与一个聊天窗口打交道：提出一个问题，得到一个答案。2025 年，Claude Code 把一个智能体放进了命令行，开发者开始把一些最繁琐、最耗时的流程交给它处理，从解析数据、现代化改造遗留系统，到在多个服务的代码库中交付功能，而这一切都与其最关键的业务系统相连。

如今，[Claude Cowork](https://claude.com/product/cowork) 把同样的能力带到了桌面端，惠及公司里的其他所有人：分析师、律师、客户经理、市场人员等等。Claude Cowork 在工作原本所在的地方与之相遇：本地文件和文件夹、Slack 和 Google Drive 等已连接的应用，以及浏览器。配合 Claude for Excel 和 Claude for PowerPoint，它还能在单个工作流中跨电子表格和幻灯片传递上下文。借助插件、Skills（技能）和命令，Claude 会变得更加强大，也能更好地适配你的工作环境。

为了帮助团队充分利用 Claude Cowork，我们编写了一份指南，逐步讲解如何在一个业务职能中部署它，包括从哪里开始、如何组织试点、常见用例，以及推动大规模采用的最佳实践。虽然其中许多示例来自 Anthropic 自己的团队和客户，包括 Thomson Reuters、Zapier 和 Jamf，但这些模式和经验教训广泛适用于各个行业和公司。

在指南中，我们分享了：

-   一个 Claude Cowork 采用成熟度模型，共五个层级，从聊天问答到部门级插件
-   如何选择你的第一个用例并组织试点评估
-   一份为期六个月的路线图，从内部推动者团队走向全组织部署
-   Anthropic 的财务、法务、销售和产品团队如何在生产环境中使用 Cowork
-   来自 Thomson Reuters、Zapier 和 Jamf 的客户案例
