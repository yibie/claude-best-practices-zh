# Anthropic 的财务团队如何用 Claude 塑造数字背后的叙事
在财务领域，你的工作是塑造数字背后的故事：解释关键指标为何变动、基于市场趋势设定预期，并把财务结果与产品战略联系起来。但人很容易把大部分时间花在确保数字正确上——在数字又一次刷新后第四次重读一份演示文稿——而不是思考这些数字意味着什么。

例如，我负责执行分析并提取指标，用于我们团队为 CFO 准备的季度董事会演示文稿。通常，一份演示文稿交付时，我已经改过好几遍。数字会一直刷新到文稿发出的当天早上，而每次刷新，评述都必须对照最新数字核对。除此之外，这份文稿是协作完成的，合作伙伴会同时更新各自的幻灯片。每一次更新都意味着整个叙事必须重新对齐基准：第 4 页的评述是否仍与第 17 页的数字对得上？有没有人引入了一个指标却没有给出定义？我得不断重读整份文稿，以确保故事仍然前后一致。

现在 Claude 替我完成所有这些工作：它承担了工作底层的完整性保障，让我的时间可以投入到上层的叙事。它也是我月度审阅流程和模型审计的一部分，为我腾出时间，让我现在可以与团队协作，或用于创造性思考以及财务中需要判断力的部分。

## 快速变化的业务全景

我于 2025 年 3 月加入 Anthropic 的企业财务与战略团队。企业财务位于财务组织的中心：其他财务团队直接与业务合作——例如，市场推广财务与销售合作——他们了解到的一切都会回流到我们这里。我们的工作是准备 CFO 和董事会需要看到的叙事：收入表现如何、利润率发生了什么变化、现金如何部署，以及这对今年余下时间意味着什么。

这个叙事必须在底层业务不断变化的同时保持连贯。在 Anthropic，这意味着产品发布、模型发布、定价变化，以及我们划分销售模式方式的转变等因素，往往都发生在同一周内。企业财务必须吸收公司全部的变化速度，同时仍向董事会交付一个自洽的故事。

## 我如何在各项工作中使用 Claude

我并行使用 [Claude Cowork](https://claude.com/product/cowork) 和 [Claude for Excel](https://claude.com/claude-for-microsoft-365)：Claude Cowork 帮我在文档或演示文稿中撰写和综合信息，而我用 Claude for Excel 直接在财务模型中与 Claude 一起编辑。

在前面提到的董事会演示文稿上，我把文件交给 Claude Cowork，让它验证每个数字和论断都能对接到单一事实来源。我还会让它像董事会成员那样阅读叙事，标出其中自相矛盾之处，或假定读者并不具备某些背景信息的地方。Claude 能捕捉到我本来会漏掉的问题，而且每次数字变动它都会做，而不只是做一次。

另一个例子是我们的月度财务审阅，那是一份 Google Doc，每个月一个标签页，结构是对照预测的差异分析。当我准备撰写某个月的内容时，我会把模型中相关的财务表格放进文档，链接支持性背景信息，然后让 Claude Cowork 用我们既有的语气写出初稿：收入为 A，对比 B，偏差 C%，由 D 驱动。我在此基础上编辑。逐月保持语气一致与数字本身同样重要，而当我引用上个月的文档时，Claude 能做到这一点。

随着 Claude 和我们的产品界面不断改进，我与它们协作的方式也在改进。例如，Claude for Excel 从无法跟踪跨标签页的引用，发展到能够追踪一张不平的资产负债表，穿过多个标签页找到根本原因。当我打开一个从未见过的模型时，我会让 Claude 先总结关键驱动因素并标出结构性问题，然后再投入时间。

在所有这些工作流中——董事会材料的叙事完整性、Sheets 和 Excel 中的模型诊断，以及 Claude Cowork 中的初稿评述——我找回了数小时时间，现在这些时间直接投入到真正需要判断力的工作中：框架搭建、情景问题，以及前瞻性分析。

| 工作流 | 频率 | 工具 | Claude 做什么 |
| --- | --- | --- | --- |
| 董事会演示文稿 | 每季度 | Claude Cowork | 核对各幻灯片之间的数字，检查叙事一致性 |
| 月度财务审阅 | 每月 | Claude Cowork | 用既定语气起草初稿评述 |
| 财务模型工作 | 按需 | Claude for Excel | 追踪跨标签页引用并诊断模型问题 |

## 上下文让一切运转起来

Claude Cowork 之所以有效，是因为它看到与我相同的上下文：文档和本地文件、邮件和 Slack，这里仅列举几个团队知识来源。当我遇到一份重要的文档时，我会把它提交到项目记忆中。当一项决策在漫长的跨职能讨论串中做出时，我会让 Claude 提取结论和推理，以便下次这个话题在董事会周期中再次出现时随手可用。

我还会为不同的受众保留不同的项目：一个用于月度审阅，一个用于董事会演示文稿。语气和惯例不同，记忆也随之不同，Claude 会相应地生成内容。

## Claude Cowork 在整个财务组织中的应用

在整个财务组织中，我的同事们使用了许多现已打包进 Claude Cowork [金融服务插件](https://www.anthropic.com/news/finance-agents)的 [Skills（技能）](https://support.claude.com/en/articles/12512180-use-skills-in-claude)。以下是 CFO 组织如今使用 Claude Cowork 的几个例子：

-   **财务与战略：** 由分析师自己通过提示词构建的交互式预测和群组仪表盘：无需 SQL 或工程介入。每日收入和指标摘要会在早上 7 点发送到领导层的 Slack。
-   **会计：** 总账到子分类账以及银行对账，差异被分类，审阅者评述作为初稿起草。三大财务报表均运行波动分析。团队中任何人都可以在 Slack 中向 Claude 提问，并获得有来源的答案。
-   **企业发展与投资者关系：** 每天基于笔记和公开数据为三到四个收购目标生成筛选报告，然后在几分钟内汇总成备忘录。团队把时间花在判断和做决定上，而不是初稿上。
-   **税务与资金：** 转让定价、研发税收抵免和关联问题均以一手来源引用作答。间接税和现金对账采用与会计相同的技能模式。

## 给财务团队上手 Claude 的建议

一年前我加入 Anthropic 时，AI 工具大多还是 LLM：擅长文本，不太擅长数字。吸引我的是看着 Claude for Excel 不断进步。我几乎能直接追踪到模型变好带来的差别。

如果你还在犹豫，从简单开始：让 Claude 读一份文档并总结，然后不断拓展边界。它在反复出现的工作流中价值最大，包括董事会周期和月度审阅，在这些场景中一致性会不断累积，项目记忆每过一轮都会更丰富。你不需要复杂的工具栈；我几乎完全依靠 Claude Cowork [项目](https://support.claude.com/en/articles/14116274-organize-your-tasks-with-projects-in-claude-cowork)、Claude for Excel 和 Google Workspace 连接器运行。

如果你不知道该用哪个 Claude 界面，直接问 Claude 就好。有 Claude 参与其中，我能跟上工作底层的变化节奏。我更快获得洞察，意外和瓶颈更少，也能把更多时间花在框架搭建和前瞻性分析上。
