# Anthropic 各团队如何使用 Claude Code

像 [Claude Code](https://claude.com/product/claude-code) 这样的智能体式编程工具能帮助开发者加速工作流、自动化重复性任务，并攻克复杂的编程项目。随着这一领域不断发展，我们每天都能从用户（包括我们自己的员工）那里了解到新的应用方式。

为了深入了解，我们与 Anthropic 各部门的员工坐下来聊了聊，了解他们在工作中如何使用 Claude Code。

虽然他们的许多用例都在意料之中——调试、浏览代码库、管理工作流——但也有一些让我们感到意外。律师构建了电话树系统。营销人员几秒钟内就生成了数百个广告变体。数据科学家在不懂 JavaScript 的情况下创建了复杂的可视化图表。

规律逐渐清晰：智能体式编程不仅仅是在加速传统开发。它正在消融技术性工作与非技术性工作之间的界限，让任何能够描述问题的人都能成为构建解决方案的人。

以下是我们了解到的情况。

### **代码库导航与理解**

公司各团队都在使用 Claude Code 帮助新员工乃至资深员工快速熟悉我们的代码库。

我们基础设施团队的新数据科学家会把整个代码库输入 Claude Code，以便快速上手。Claude 会读取代码库中的 [CLAUDE.md](http://claude.md/) 文件，识别出相关文件，解释数据流水线依赖关系，并展示哪些上游数据源为仪表盘提供数据，从而替代了传统的数据目录工具。

我们的产品工程团队把 Claude Code 称为任何编程任务的"第一站"。他们会让它找出修复 bug、开发功能或进行分析时需要检查哪些文件，省去了在构建新功能之前手动收集上下文这一耗时的过程。

### **测试与代码审查**

智能体式编程工具尤其受欢迎的一点，是它们能够自动化两项关键但繁琐的编程任务：编写单元测试和审查代码。

产品设计团队使用 Claude Code 为新功能编写全面的测试。他们通过 GitHub Actions 自动化了拉取请求（PR）评论，由 Claude 自动处理格式问题和测试用例重构。

安全工程团队将他们的工作流从"设计文档 → 粗糙代码 → 重构 → 放弃测试"转变为：先让 Claude 给出伪代码，引导它进行测试驱动开发，并定期检查进展。这样产出的代码更可靠、更易于测试。

智能体式编程还可以用来把测试翻译成其他编程语言。例如，当推理团队需要在 Rust 这类不熟悉的语言中测试功能时，他们会说明想要测试的内容，Claude 会用代码库的原生语言编写逻辑。

### **调试与故障排查**

生产问题需要快速解决，但在压力之下试图理解陌生的代码往往会导致延误。对公司许多团队来说，Claude Code 通过实时分析堆栈追踪、文档和系统行为，加速了诊断与修复。

在事故处理期间，安全工程团队会把堆栈追踪和文档输入 Claude Code，以追踪代码库中的控制流。过去通常需要 10-15 分钟手动排查的问题，现在的解决速度快了 3 倍。

借助 Claude Code，产品工程团队有了在陌生代码库中处理 bug 的信心。他们会问 Claude："你能修复这个 bug 吗？这是我看到的行为"，然后审查它提出的解决方案，而无需依赖其他工程团队的协助。

有一次，当 Kubernetes 集群停止调度 pod 时，数据基础设施团队使用 Claude Code 诊断问题。他们输入了仪表盘截图，Claude 引导他们逐个菜单地浏览 Google Cloud 的 UI，直到发现是 pod IP 地址耗尽。随后 Claude 提供了创建新 IP 池并将其添加到集群的确切命令，在系统中断期间为他们节省了宝贵的 20 分钟。

### **原型设计与功能开发**

构建新功能传统上需要深厚的技术知识和大量的时间投入。Claude Code 支持快速原型设计乃至完整的应用开发，让团队无论编程水平如何都能快速验证想法。

产品设计团队的成员会把 Figma 设计文件输入 Claude Code，然后设置自主循环，让 Claude Code 编写新功能的代码、运行测试并持续迭代。他们给 Claude 提出抽象的问题，让它自主工作，然后在最终完善之前审查解决方案。有一次，他们让 Claude 为 Claude Code 自身构建 Vim 键位绑定，几乎不需要人工审查。

借助 Claude Code，产品设计团队发现了一个意想不到的用途：梳理错误状态、逻辑流和系统状态，以便在设计阶段就识别出边缘情况，而不是等到开发阶段才发现。这从根本上提升了他们的初始设计质量，并在后续节省了数小时的调试时间。

尽管不精通 TypeScript，数据科学家们仍使用 Claude Code 构建完整的 React 应用，用于可视化 RL 模型的性能表现。在沙箱环境中进行一次提示后，该工具就能从零编写出完整的 TypeScript 可视化代码，而他们自己并不理解这些代码。考虑到任务本身很简单，如果第一次提示效果不够好，他们会稍作调整再试一次。

### **文档与知识管理**

技术文档往往散落在 wiki、代码注释和团队成员的脑子里。Claude Code 通过 MCP 和 CLAUDE.md 文件将这些知识整合为易于获取的形式，让每个需要的人都能获取这些专业知识。

没有机器学习背景的推理团队成员依赖 Claude 来解释模型特有的函数。过去通常需要一小时 Google 搜索，现在只需 10-20 分钟——研究时间减少了 80%。

安全工程团队让 Claude 摄取多个文档来源，生成 Markdown 运行手册和故障排查指南。这些精简后的文档成为调试真实生产问题时的上下文，往往比在完整知识库中搜索更高效。

### **自动化与工作流优化**

智能体式编程工具帮助团队构建自定义自动化，而这类工作传统上需要专职的开发资源或昂贵的软件。

增长营销团队构建了一个智能体式工作流，用于处理包含数百条广告的 CSV 文件，识别表现不佳的广告，并在严格的字符限制内生成新的变体。该系统使用两个专门的子智能体，几分钟内就能生成数百条新广告，而不是耗费数小时。

他们还开发了一个 Figma 插件，能够识别画框，并通过替换标题和描述以编程方式生成多达 100 个广告变体，将数小时的复制粘贴工作缩短到每批广告半秒钟。

在一个尤为独特的用例中，法务团队创建了原型"电话树"系统，帮助团队成员联系到 Anthropic 合适的律师，展示了各部门如何在缺乏传统开发资源的情况下构建自定义工具。

### **用 Claude Code 解锁新的可能**

这些故事揭示了一个规律：当你专注于 Claude Code 能够增强的人类工作流时，它发挥的作用最大。最成功的团队把 Claude Code 当作思考伙伴，而不是代码生成器。

他们探索可能性、快速制作原型，并在技术与非技术用户之间分享发现。这种人与 AI 之间的协作方式，正在创造出我们才刚刚开始理解的机遇。
