# 在 Claude Cowork 中使用 Claude Fable 5
Claude Fable 5 是 Anthropic [能力最强的通用可用模型](https://www.anthropic.com/news/claude-fable-5-mythos-5)，专为长时间运行、复杂且异步的工作而打造。Claude Fable 5 尤其擅长长时间独立执行多步骤工作流（例如开展深度研究并将其融入初稿备忘录、在生成董事会演示文稿前进行尽职调查，或遍历一个文件夹对多份合同进行红线标注，等等），并在过程中不断测试和评估自己的结果。

要最大化发挥模型的能力，需要改变你与它的协作方式。随着模型不断进步，我们也持续完善了让 Claude 发挥更大作用的建议，包括[提示词最佳实践](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)、提供上下文，以及[构建 Skills](https://claude.com/resources/tutorials/teach-claude-your-way-of-working-using-skills) 来沉淀可重复的流程，比如每周团队更新、销售电话准备或客户反馈分析。这些做法在 Claude Fable 5 上依然重要，事实上，有了这些做法，模型的表现会更好。

Claude Fable 5 会将你的上下文、偏好和 [Skills](https://claude.com/resources/articles/skills-explained) 贯穿应用于整个任务，即便是需要数天才能完成的任务；而此前的模型在长时间跨度中可能会失去线索，需要你反复提醒。与它协作就像与一位能力极强的同事共事：你说明情况，就什么样的最终结果算得上出色达成一致，然后让这位同事去干活。你花在检查每一步上的时间更少，于是能把更多时间用于决定这项工作应该做成什么样。

我们的 [Claude Fable 5 提示指南](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5)提供了能力改进的详细清单，以及推荐的行为与提示方式调整。本文介绍其中一些改进如何应用于 Claude Cowork——Anthropic 面向知识工作的智能体式 AI 系统。

## Claude Fable 5 如何与 Claude Cowork 互补

Claude Cowork 专为产出完成的工作成果而构建。给它一个目标，其余的交由它管理，即便任务庞大而复杂。大任务会被拆分成多个部分并行运行，每个部分都有自己的子智能体——一个独立的 Claude 实例，负责完成任务的某一部分并汇报结果。Claude 正是以此快速处理大量信息。Claude 还通过在开始时制定计划来管理大型任务，并能在过程中对照计划检查自己的结果。

Claude Fable 5 在[长时程、复杂任务上大幅领先于我们的其他模型](https://www.anthropic.com/news/claude-fable-5-mythos-5)，而 Claude Cowork 的任务往往正是如此：包含数十个步骤，每一步都建立在前一步之上。以根据今年实际数据编制明年预算这样的项目为例。Claude 会获取并读取电子表格，提取运行率，对每个项目进行预测，将预测与目标核对，并撰写总结。如果它早期误读了一个运行率，这个错误会传导到之后的每一项预测中。Claude Fable 5 会在开始前规划工作流，并在过程中检查结果，因此能在任务运行期间发现误读的数字并加以纠正。

## 决定何时使用 Claude Fable 5

Claude Fable 5 并非 Claude Cowork 的默认模型，你需要主动选择它。截至本文发布时，默认模型是 Claude Sonnet 5，对于你自己快速处理就能搞定的日常任务，它是合适的选择。Claude Opus 是深度工作的可靠选择，适用于形态清晰、你知道最终结果长什么样的工作。Claude Fable 5 则适用于那些感觉最复杂或最模糊、此前的模型可能无法胜任的项目。它会花更多时间思考，也会消耗你更多的用量额度，但对于耗时或出错代价高昂的工作，这可能是值得的。我们建议将 Claude Fable 5 留给你最重要的工作，尤其是那些使用多种工具、需要一系列判断的工作。

你还可以通过 Claude 的 effort 设置进一步调整选择。在更高的 effort 下，Claude Fable 5 会在启动任务前做更多规划，并在整个运行过程中更频繁地检查。对于你期望 Claude 从头到尾完成的复杂或多步骤项目，请保持较高的 effort。在较低的 effort 下，你会得到更快的响应，同时仍能利用 Claude Fable 5 的智能。可以考虑将它用于那些仍需要前沿判断力、但不需要深度探索的任务，例如由许多简单步骤组成的智能体式运行，或结果易于 Claude 自行检查的工作。在我们的测试中，较低 effort 下的 Claude Fable 5 常常达到或超过早期模型在最高 effort 水平下的表现。若想更深入地了解其内部机制，我们解释了[模型选择与 effort 在 Claude Code 中如何相互作用](https://claude.com/resources/articles/claude-model-and-effort-level-in-claude-code)。

同样值得注意的是，Claude Fable 5 附带了一套新的分类器：这些独立的 AI 系统用于检测与网络安全或生物化学相关的请求中可能存在的滥用行为。当它们触发时，响应会自动改由 [Claude Opus 4.8](https://support.claude.com/en/articles/15363606-why-claude-switched-models-in-your-conversation-with-fable-5) 处理，并且每次发生这种情况时都会告知用户。Opus 4.8 本身就是一个能力很强的模型，此后对话会继续停留在 Opus 上；要回到 Claude Fable 5，请开启一个新对话。我们保守地调整了这些防护措施，以便能够安全且快速地发布一个[面向通用场景的 Mythos 级模型](https://www.anthropic.com/news/claude-fable-5-mythos-5)，因此它们有时会拦截无害的请求，包括 Claude Cowork 中仅仅涉及相关话题的措辞。我们正在完善这些防护措施，以减少此类误报。

## 从一个想法起步

当你启动一项任务时，并不总是清楚自己想要达成什么。在这个早期阶段，Claude Fable 5 可以成为强大的思考伙伴，而在 Claude Cowork 中，它会基于你的 Skills、工具和知识来工作。

例如，如果你看到一条与你的行业或公司相关的新闻公告，你可以问 Claude：“这是那条公告，结合你对我所在组织的一切了解，告诉我这对我们意味着什么变化。”你阅读输出，随着你开始形成策略，Claude 会制定计划来产出你所需的材料，而且就在进行头脑风暴的同一个 Claude Cowork 对话中开始。

在 Claude Cowork 中进行头脑风暴，能让模型用你的真实材料来思考：它可以在你们交谈时读取你共享的文件、使用你已连接的工具，从而给出相关的建议。它会在一个想法还容易改变时就发现其中的缺口，并向你展示你未曾考虑过的方向。而当任务在同一个对话中开始时，Claude Fable 5 已经掌握了你确定的目标、你提出的约束，以及你一路做出的决定。

例如，Anthropic 的一位数据科学家带着一个新分析仪表盘的想法来到 Claude Cowork，而当时团队还在琢磨这个仪表盘应该展示什么。由于 Claude Fable 5 能在对话期间读取团队的使用数据，它知道哪些问题需要数周才会被注意到，并对本可以更早发现这些问题的指标进行了排序。到对话结束时，这位数据科学家已经得到了一份值得添加的指标清单和一个可点击的原型。

以下两个提示词可以帮助你把想法演化为产出：

-   **让 Claude 采访你：**“在开始之前，问我所有你需要了解的问题，以便把这件事做对。”
-   **请它给出方向：**“这大致就是我想要的。给我三种你可以采用的方向，每个方向附一个快速样例。”


## 用约束提供上下文

上下文是 Claude 工作的依据，在 Claude Cowork 中，这意味着你的提示词、你共享的文件和文件夹，以及你连接的任何工具，例如 Asana、Hubspot、Jira、Slack 或[其他工具](http://claude.com/connectors)。

当你在 Claude Cowork 中给 Claude Fable 5 一项任务时，想想你会如何向同事交代一份报告。你不会递给他们一列规则，但多半会告诉他们这份报告是给谁的、什么时候需要、必须达成什么，然后信任他们在此基础上做出好的判断。Claude Fable 5 的工作方式也是如此。

约束仍然有用：“控制在两页以内，使用平实的语言”是个不错的指令。但约束只告诉 Claude 不要做什么。上下文告诉它这项工作的目的是什么，这样它就能在你约束未预料到的情况下做出正确的判断。

Claude Fable 5 之所以能很好地处理长时程、多步骤任务，部分原因就在于这种上下文：当它在工作过程中遇到问题或决策点时，它会从你共享的上下文中寻找答案。它还会利用这些上下文在过程中检查自己的工作，所以请给它一些具体的参照来判断，比如一份报告的早期草稿和最终版本，Claude 会根据两者之间的变化推断出你的标准是什么。

上下文还能让 Claude 理解你的处境，从而推断或找出你在提示词中从未明确说明的细节。共享更多上下文，能让 Claude 在你无法塞进提示词的知识库中搜索更广的范围。

关于上下文很多的对话，有一点需要注意：为了保持跟进，Claude 会在你发送每条新消息时重新读取整个对话，因此长对话可能会消耗你更多的用量。在新对话中开始新任务会有所帮助。定时任务也计入你的额度，所以请偶尔检查你的额度，并关闭不再需要的定时任务。

## 将更大、更复杂的工作委派给 Claude Fable 5

你可能习惯了把任务拆成若干部分，逐一提示 Claude。Claude Fable 5 需要的这类中间提示词要少得多，因此你可以在 Claude Cowork 中委派完整的工作。

当流程对你很重要时，你仍应自己写出步骤，例如某个指标每次都必须以完全相同的方式计算。但如果重要的是结果，就描述目标，让 Claude 完成其余部分。分步提示词还可能把它限制在你所想到的步骤内；而目标则给它空间去寻找更好的路径。

在 Claude Cowork 中委派，意味着把一个你通常会自己做的决定交给 Claude。以下三种方式可以做到这一点：

-   **委派方法：**把材料交给 Claude，描述你想要的成果，例如：“这是上个季度的客户反馈。找出取消量上升的原因，以及我们应该改变什么。”处理那个文件夹可能有多种合理的方式，正确的方式取决于反馈的内容。这正是 Claude Fable 5 擅长做出的选择：它读完全部内容，选定一种方法，并在把结论交给你之前对照反馈进行验证。你无需指定它如何得出答案，就能评判这个答案。
-   **委派流程：**Skill 会教 Claude 你的团队使用的某个流程——你如何构建报告、格式化演示文稿、运行分析。你无需说明使用哪些 Skills 或以什么顺序使用。只要说“按我们一贯的方式整理季度回顾”，Claude Fable 5 就会在合适的时机选用合适的 Skills。
-   **委派时机：**对于你希望重复进行的工作，描述成果，Claude 会设置好时间安排，将其变为一项周期性任务：“我希望每周一一开始就知道流水线里发生了什么变化，以及哪些需要做决定。”

把比你以往交给 AI 的更困难的工作交给 Claude Fable 5，甚至是那些你以为不可能完成的工作。即便工作杂乱或不清楚，或者可能需要数小时乃至数天才能完成。描述它，看看模型能否在那个层面上工作。选一个你负责的成果，说明你会如何评判它，然后让 Claude 提出达成它的步骤。其中一些工作可能会变成自行运行的定时任务。Claude 可以把流程保存为 Skill 并放到时间表上，通过你已连接的工具来完成。

## 审查 Claude 的思考过程

Claude Fable 5 之所以能承担长时程工作，部分原因在于它懂得如何制定并很好地遵循计划。在 Claude Cowork 中，你可以在 Claude 工作时看到这个计划：对话旁边的面板会列出它打算做什么，然后是它正在读写的文件以及它正在使用的工具和 Skills。

这个面板是你及早发现问题并调整方向的机会。否则你会在最终产出中发现的错误，此时会以计划中一个错误步骤的形式显现出来。你可以用一句话纠正计划，Claude 会据此调整，而无需从头开始。



工作完成后，像审查同事的工作那样审查它：打开 Claude 产出的文件并阅读。如果有什么看起来不对，运行的记录仍在对话中。往回滚动查看 Claude 工作时列出的步骤，包括它读取的文件和使用的工具，并展开它的思考，查看某个决定背后的推理。或者直接问：“这个数字是从哪里来的？”Claude 会为你指出出处。

从你知道如何验证的工作开始，比如你团队下季度计划的初稿。如果你对优先事项很熟悉，就能很快判断 Claude 的成果是否站得住脚。随着结果被证明可靠，再委派更大的工作。

## 投入完善你的 Claude Cowork 配置

能力更强的模型会提升你所建立的每一项连接的价值，从你共享的文件夹到你的团队日常使用的工具。以下是我们关于为 Claude Fable 5 提供其最佳工作所需上下文的建议：

-   **连接你的工具：**首先将 Claude 连接到[你日常使用的工具](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)，比如你的电子邮件、日历、文档或团队的聊天工具。每一项连接都会拓宽 Claude 无需你手动复制内容就能做的事情。Claude Fable 5 善于判断何时值得使用某个工具：在你的工具已连接的情况下，它会注意到答案就在你的日历或某个聊天线程中，并主动去获取，而不是等着被指过去。
-   **调整写作风格以贴合你的声音：**每个新模型都带有自己的写作默认设置：语气、长度，以及它在输出中最先想到的措辞。你可能会注意到 Claude Fable 5 有某些默认设置，[比如在较长的会话中写作风格更简洁或更难跟上](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5)。语气、口吻和风格很容易定制；你可以通过提示词或将其加入项目指令来按你的偏好进行调整。例如，你可以添加类似“使用平实、直接、简明的语言”这样的内容。如果你使用记忆功能，请偶尔查看 Claude 保存了哪些关于你写作偏好的内容。对于你想要特定口吻的文档，可以使用连接器或现有文件，让 Claude 通读你过去的写作，并将发现的内容保存为一项 Skill，供你下次做类似工作时调用。我们发现 Claude Fable 5 比早期模型更严格地遵循常设指令，也更善于在需要时使用已保存的材料。
-   **重新审视你为早期模型所做的设置：**为早期模型编写的已保存指令，比如 Skills 和记忆文件，往往带有那个模型所需的纠正。沿用到新模型上，旧的纠正可能会约束新模型。让 Claude Fable 5 做一次审计：“翻看我的 Skills 和已保存的记忆。哪些仍然适用，哪些是为更早的模型编写的？”

## 接下来会怎样

随着前沿智能持续演进，Claude Cowork 将变得越来越强大，能够支持更长时间运行的工作，并解锁更多知识工作用例。学习如何编写提示词、管理上下文、检查 Claude 的工作以及委派任务，将帮助你充分利用 Claude Fable 5 以及未来模型所提供的一切。
