# 投资回报率

> **分类**：成本与性能 ｜ **英文**：ROI ｜ **出现于 4 篇文章**

## 摘要

投资回报率（ROI）是衡量 AI 投入与业务收益之比的量化指标，用来判断一项 AI 投资是否值得、是否产生了可证明的价值。它之所以重要，是因为 AI 采用通常按用量计费、成本随采用率增长，组织必须同时控制成本并证明影响，才能把试点转化为企业级转型。

## 关键做法

- 把成本与价值放在同一套度量里：明确用量是付费对象，也是价值体现之处，避免只盯账单不看收益。
- 用“控制、跟踪、证明”三个杠杆组织工作：先控制支出，再跟踪使用情况，最后用数据证明影响。
- 理解成本驱动因素：账单由任务消耗的 token 数量与所用模型共同决定，token 消耗随任务复杂度和对话长度增长。
- 将模型与任务匹配，作为主要的成本控制手段之一，避免用高成本模型处理简单任务。
- 优先选择与战略性业务目标一致的高 ROI 机会，而不是对所有系统平均用力。
- 在复杂环境中先解决可建模性问题：系统分散、季节性需求周期等都会让 ROI 难以建模，需要先打通数据与流程。

## 在 Claude 里的用法

在 Google Cloud 上使用 Claude Code 时，组织可以围绕控制、跟踪、证明三个杠杆管理按用量计费的支出，并结合模型与任务匹配来优化成本。零售等行业的实践则通过具体部署体现回报，例如 Shopify 用 Claude 驱动 Sidekick 将商家自然语言问题转为 ShopifyQL 查询，L'Oréal 构建以 Claude 为核心、编排 15 个以上专用智能体的多智能体系统服务全球员工。代码现代化场景中，可用 ROI 视角筛选与业务目标一致的现代化机会。

## 常见误区

- 把投资规模当作瓶颈：实际上投资本身往往不是瓶颈，系统分散、需求周期波动和人才短缺才是 ROI 难以建模的原因。
- 只关注成本控制而忽略证明价值：采用率驱动用量，用量既是成本来源也是价值所在，单方面压缩支出会掩盖真实影响。
- 用聊天场景的 token 预期估算智能体式工具：Claude Code 这类工具每个任务消耗更多 token，因为它要读文件、运行工具并进行多步推理。
