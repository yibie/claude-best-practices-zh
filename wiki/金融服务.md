# 金融服务

> **分类**：行业与场景 ｜ **英文**：financial services ｜ **出现于 2 篇文章**

## 摘要
金融服务是银行、保险、资产管理等受监管行业的统称，其业务对合规、数据安全和遗留系统改造有较高要求。Claude 官方以两场专题网络研讨会讨论 Claude Code 在该领域的应用，说明它是 Claude Code 落地的重要行业场景之一。

## 关键做法
- 从具体任务切入：官方材料把金融服务的使用路径概括为“从分析数据到改造遗留系统”，可先选数据分析类任务试点。
- 关注遗留系统现代化：把老旧系统的理解、迁移与重构作为该行业的主要落地场景来规划。
- 结合受监管行业的特点评估使用方式，在引入工具时同步考虑合规与审计要求。
- 参考官方网络研讨会中 Claude Code 负责人分享的实践经验，了解该行业的典型用法。

## 在 Claude 里的用法
在金融服务场景中，Claude Code 主要用于分析数据和改造遗留系统两类工作。可通过 Claude 官方资源页观看两场专题网络研讨会（其中一场由 Claude Code 负责人 Boris Cherny 主讲），了解具体用法。若涉及团队协作与知识沉淀，可结合 MCP、Skills 等能力把行业流程固化下来。

## 常见误区
- 把金融服务当成单一场景：它涵盖银行、保险、资管等不同业务，落地方式需分别设计。
- 只关注模型能力而忽略监管要求：受监管行业的合规约束会直接影响工具的使用方式。

## 相关概念
- [Claude Code](Claude-Code.md) —— 官方材料中金融服务场景的核心产品，用于数据分析与遗留系统改造。
- 遗留系统现代化 —— 官方把其列为金融服务中使用 Claude Code 的主要方向之一。
- [MCP](模型上下文协议.md) —— 可用于把金融业务系统与数据接入 Claude 的集成方式。
- Skills —— 可用来固化金融场景中可复用的流程与规范。
