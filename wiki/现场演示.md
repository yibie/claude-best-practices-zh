# 现场演示

> **分类**：企业落地与组织 ｜ **英文**：live demos ｜ **出现于 2 篇文章**

## 摘要
现场演示（live demos）指在活动或网络研讨会中，实时展示产品完成真实任务的过程。它是 Claude Code 相关 webinar 的组成部分，用于让观众直观看到产品在真实场景中的工作方式，而非仅停留在概念介绍。

## 关键做法
- 选择真实任务而非预设脚本，让演示反映产品在实际工作中的表现。
- 在活动流程中把现场演示与产品起源故事、最佳实践等内容搭配呈现，形成从背景到实操的完整叙事。
- 面向服务交付等具体场景设计演示内容，使观众能将演示映射到自身业务。
- 由熟悉产品的一线负责人主导演示，便于在过程中解释决策与操作。

## 在 Claude 里的用法
在 Claude Code 相关的网络研讨会中，现场演示被用来实时展示 Claude Code 完成真实任务的过程，例如在 "Claude Code Live" 与 "Claude Code for Service Delivery" 两场 webinar 中均有采用。演示通常与产品起源故事和最佳实践分享结合，帮助参会者理解 Claude Code 的实际能力边界与使用方式。

## 常见误区
- 把现场演示理解为录屏或静态截图展示，失去"实时完成真实任务"的核心价值。
- 只演示顺利路径，忽略真实任务中可能出现的偏差与调整过程。

## 相关概念

- [Claude Code](Claude-Code.md) —— 现场演示所展示的产品对象，两场 webinar 均以其实时完成任务为核心内容。
