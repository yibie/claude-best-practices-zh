# 商家智能体

> **分类**：行业与场景 ｜ **英文**：merchant agent ｜ **出现于 2 篇文章**

## 摘要

商家智能体（merchant agent）是面向店铺运营者的智能体类型，用于分析销售与库存数据并给出促销建议。它是 Claude 商务智能体蓝图中的两类参考实现之一（另一类为购物智能体），对零售、旅游、电信、票务等平台的运营侧自动化具有直接价值。

## 关键做法

- 从官方蓝图入手：使用商务智能体蓝图提供的执行框架（harness）、模式和护栏，让工程团队在几天内把商家智能体跑起来，而不是从零搭建。
- 先看演示再写代码：在自助演示中观察商家智能体的实际运行效果，再决定定制方向。
- 基于参考实现定制：以仓库中商家智能体的完整可运行实现为起点，将其适配到自己的商品目录、政策与品牌。
- 借助 Claude Code 插件加速落地：利用蓝图附带的 Claude Code 插件快速上手并协作完成定制。
- 按需选择构建方式：可用 Messages API、Agent SDK 或 Claude Managed Agents（beta）构建同一套实现。

## 在 Claude 里的用法

在 Claude 平台上，商家智能体可通过 Messages API、Agent SDK 或 Claude Managed Agents（beta）构建，官方仓库提供了完整可运行的参考实现。实践中通常先在自助演示中验证效果，再用 Claude Code 配合蓝图插件，把参考实现定制到自己的商品目录、政策和品牌上。网络研讨会（如 Ali Shazal 主讲的场次）还会讲解零售、旅游、电信、娱乐领域的参考实现，并设有构建、认证、延迟等问题的现场问答。

## 常见误区

- 误以为需要从零开发：蓝图已提供执行框架、模式、护栏与可运行实现，重点是定制而非重建。
- 误以为商家智能体等同于购物智能体：二者是蓝图中的两类不同参考实现，前者面向店铺运营者，后者面向消费者。
